# Hunter, Challenge and local replay contracts

These features extend the browser game while Levels and Survival keep their rules and save key.

Hunter is a separate player-controlled snake on the same 20 × 20 arenas. A snake starts with four cells facing right. It moves automatically at the selected difficulty cadence; a two-turn buffer accepts perpendicular turns and rejects reversals against the last queued heading. Collecting a mango adds one cell and 100 points times the existing difficulty multiplier. Walls, stones and occupied body cells lose; entering a departing tail is legal unless growing. Filling every available cell wins. Food uses a seeded integer generator and a bounded list of free cells, with no retry loop. Start, pause, resume, restart and keyboard/touch turning belong to this mode. Dash and close-call abilities remain exclusive to mango modes.

Local Challenge uses the existing Survival rules with a fixed, versioned configuration. Canopy Sprint uses Canopy Clearing, Normal difficulty and a 15-second survival objective. Root Runner uses Root Divide, Hard difficulty and a 20-second objective. Wild Escape uses Wild Heart, Normal difficulty and a 25-second objective. A fixed seed selects a safe mango start cell. Reaching the objective wins; capture loses. Compare survival time first, then close calls; results are stored separately by challenge ID and rules version. These are local practice challenges.

Replays record simulation-step directions and ordered steer, clear, dash, pause and resume actions. Consecutive identical step directions are compressed. Metadata contains format, game/rules versions, mode, arena, difficulty, seed and optional challenge ID. Only completed runs are saved. Version/shape/size bounds reject incompatible or malformed records. Playback uses the same pure engines; a final state fingerprint detects mismatches. Paused wall time, audio, rendering, storage IDs and dates are outside replay guarantees. Saves hold at most three replays and 20,000 action groups per replay, with a 250 KB serialized limit. Longer runs continue playing without replay retention.

A compatible mango replay may be drawn as a faint turquoise outline during another run with matching mode, arena and difficulty. Its independent simulation cannot participate in collisions, scores, input or persistence. New modes and replay browsing mount on separate routes, with one active simulation per game mount.
