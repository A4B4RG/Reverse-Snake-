# Technical decisions

1. Keep the pure 20 ms simulation and Canvas rendering. Board dimensions are explicit state, not a global grid. A ResizeObserver derives them from the entire available rectangle, and resize is an ordered simulation action. Actor remapping rebuilds a legal connected body and retains progress; it may visibly relocate actors when the board shape changes.
2. Preserve the Wild Heart fix: idle fruit must be caught, and newly planned lunges respect known route corners. An already committed lunge may still be baited into a crash. Learned target anticipation and direction preferences operate inside legal route selection. Levels hunger/shrinking, Survival respawns, scores, dash and close-call boosts retain their contracts.
3. Implement two deterministic neural classifiers with online supervised behavior imitation. This small local network needs no server, pretrained model or TensorFlow dependency. Actual successful human moves update bounded weights by backpropagation; inference affects both hunting and evasion. Difficulty changes anticipation confidence/cadence and imitation influence as well as existing speed/commitment. This is not reinforcement learning or a promise of monotonically better play.
4. Store learning and cosmetics separately from existing scores. Save learned state periodically and on pause, outcome and navigation, retaining the in-memory model if storage fails. Score records omit weights. Replay snapshots carry initial weights and record every resize/input so deterministic playback includes training. Preserve the old engine only for legacy format-1 playback; new matches use the current engine.
5. Use shared code-native fruit artwork and four distinctive snake patterns. Render a ghost to a transparent intermediate sprite and composite once at 32% opacity, preventing overlapping leaf/body draws from accumulating beyond that opacity. A separate recorded cursor animates the pause background; it cannot mutate the frozen live state. Respect reduced motion.
6. Allocate viewport space with flex/grid. Canvas fills the outer rectangle and uses independent row/column counts. The desktop controls section is bottom-aligned. Short screens retain selectable setup, accessible menus and 44 px touch controls. Dialogs and narrow skin rows may scroll internally.
7. Preserve default light and the original dark theme with the click/tap/keyboard Menu. The main Fruit route and Hunter route omit their own mode links. Theme changes redraw presentation and never advance live paused state, even while an independent paused preview is playing.
8. Retain Canvas pending evidence of a concrete benefit from Phaser. Online accounts/leaderboards, an editor schema and native Android packaging require separate product/device/backend work and are outside this update. The older ML deferral is superseded by the explicit learning requirement implemented here.
9. Preserve historical Python/native reference files and `PROJECT_STATUS.md`. Keep third-party font/icon notices and the scoped minimatch security override. No project-wide licence is inferred for the owner.
10. Deliver through the existing GitHub main/Vercel integration. The user explicitly waived hosted Preview/production browser verification after declining access; document that gap and do not bypass it. Local and actual GitHub CI verification establish source behavior, not a particular deployed Vercel version. Rollback uses a reviewed revert and the existing deployment history, without force-pushing.
