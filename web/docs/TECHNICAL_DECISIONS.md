# Technical decisions

1. Retain the pure 20 ms mango simulation and Canvas renderer. Hunter has its own pure state and engine; Challenge calls the existing Survival engine through a fixed objective adapter. Shared grid, arena and direction data retain their genuine common semantics. A route mounts one game scheduler; playback runs a separate recorded simulation only on its own route. A mango ghost is independent presentation data.
2. Fix the reproduced Wild Heart Levels defect by extending existing obstacle/body distances to both modes. Newly planned lunges shorten at known corners. Existing commitments, hunger, shrinking, boosts and score formulas remain unchanged.
3. Keep reverse-snake:v1 data compatible. Add bounded versioned keys for extra-mode results and completed replays. Seeded food uses integer arithmetic and a free-cell list; no random retry loop. Replay captures step directions and ordered actions, compresses identical steps, and checks final state. Wall-clock/audio/IDs/dates are outside deterministic guarantees.
4. Fit the game with flex/grid viewport allocation and a square size-container canvas. Help and scores move through an accessible menu; dialogs scroll internally. Small screens retain setup and 44 px direction buttons. No CSS zoom or stretched board.
5. Retain Canvas pending a measured benefit from Phaser. Historical migration proposals predate the current conditional specification. No Phaser package, WebGL dependency or duplicate game engine has been introduced. Performance evidence is recorded in PERFORMANCE.md; a future port must compare identical states and preserve this renderer until parity is proven.
6. Online accounts/leaderboards are deferred: there is no agreed online feature or configured backend requirement. Current scores remain local practice records. Adding authentication, data policies and score verification requires an actual product decision.
7. The editor is deferred until custom-arena schema, spawn/reachability and hazards are defined as product requirements. Android packaging is deferred until genuine Android-browser validation; no physical device is available to this run. ML is deferred because conventional pursuit now resolves the reported routing defect and there is no measured ML research question.
8. Repair only the affected security dependency. TypeScript ESLint 8.72.2 requires advisory-affected minimatch 10; a compatible audit fix did not resolve it. Override minimatch to 11.0.1 only under typescript-estree. Clean install, named API compatibility, tests and lint were checked. Full audit now has zero findings.
9. Preserve historical Python source and confirmed zero-byte native placeholders. Untrack generated bytecode without deleting local files. Do not select a project-wide legal licence for the owner; copied third-party asset notices preserve their existing terms.
10. Release through the existing GitHub/Vercel integration. Candidate branch CI and actual Preview verification precede main. The baseline commit is a rollback checkpoint. No force-push or replacement hosting project.
