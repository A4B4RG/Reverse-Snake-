# Technical decisions

1. Keep the pure 20 ms simulation and Canvas rendering. Board dimensions are explicit state, not a global grid. A ResizeObserver derives them from the entire available rectangle, and resize is an ordered simulation action. Actor remapping rebuilds a legal connected body and retains progress; it may visibly relocate actors when the board shape changes.
2. Preserve the Wild Heart fix: idle fruit must be caught, and newly planned lunges respect known route corners. An already committed lunge may still be baited into a crash. Learned target anticipation and direction preferences operate inside legal route selection. Levels now requires movement-based score targets and saved sequential unlocks without an automatic ending. Store qualification and best star ratings live; voluntary finish is a replay action. Hunter has separate Levels/Survival progress. Food hunters grow by active time, shorten only after misses/collisions, stun in place and reverse from their tails. A continuous body splits once into two independent hunters after 60 seconds and at least 18 cells; proposals are resolved together so bodies cannot overlap and double collisions preserve both complete bodies. Hunter remains one controlled snake. Survival time scoring, dash and close-call boosts retain their contracts. Full wall-cell footprints preserve terrain density as boards expand.
3. Implement two deterministic neural classifiers with online supervised behavior imitation. This small local network needs no server, pretrained model or TensorFlow dependency. Actual successful human moves update bounded weights by backpropagation; inference affects both hunting and evasion. Difficulty changes anticipation confidence/cadence and imitation influence as well as existing speed/commitment. This is not reinforcement learning or a promise of monotonically better play.
4. Store learning and cosmetics separately from existing scores. Save learned state periodically and on pause, outcome and navigation, retaining the in-memory model if storage fails. Hunter power-ups use seeded clear-cell placement, active-clock durations (10-second double speed, 5-second food freeze), and eight-second replenishment. Score records omit weights. Replay snapshots carry initial weights and record every resize/input so deterministic playback includes training. Preserve canopy-2 and orchard-3 engines for their original recordings and terrain; new matches use jungle-6. Retain orchard-5, orchard-4 and their board geometry for preceding releases. Store Levels unlocks in the existing versioned score save and retain progress when clearing score history.
5. Use shared code-native fruit artwork and four distinctive snake patterns. Render a ghost to a transparent intermediate sprite and composite once at 32% opacity, preventing overlapping leaf/body draws from accumulating beyond that opacity. A separate recorded cursor animates the pause background; it cannot mutate the frozen live state. Respect reduced motion.
6. Allocate viewport space with flex/grid. Canvas fills the outer rectangle and uses independent row/column counts. A flex column groups the desktop game frame with its keyboard guide directly underneath; setup stays in the adjacent sidebar. The main hero uses smaller typography and spacing. Compact screens place setup in the click/tap Menu and hide the hero/sidebar to maximize board space. One pair of named character dropdowns persists across rounds and routes. Directional swipes set continuing input; double-tap invokes dash in the last direction. Taps do not steer. There is no arrow pad or Dash button. Menu/dialog content may scroll internally. Fullscreen restores canvas focus and suppresses transition-only blur; actual page hiding still pauses. Keep the Next map row height stable when enabled.
7. Preserve default light and the original dark theme with the click/tap/keyboard Menu. The main Fruit route and Hunter route omit their own mode links. Theme changes redraw presentation and never advance live paused state, even while an independent paused preview is playing.
8. Retain Canvas pending evidence of a concrete benefit from Phaser. Online accounts/leaderboards, an editor schema and native Android packaging require separate product/device/backend work and are outside this update. The older ML deferral is superseded by the explicit learning requirement implemented here. A PvP query is addressed in ONLINE_PVP.md: keep Vercel frontend hosting and add an authoritative realtime match service; a custom domain is optional.
9. Preserve historical Python/native reference files and `PROJECT_STATUS.md`. Keep third-party font/icon notices and the scoped minimatch security override. No project-wide licence is inferred for the owner.
10. Deliver through the existing GitHub main/Vercel integration. The user explicitly waived hosted Preview/production browser verification after declining access; document that gap and do not bypass it. Local and actual GitHub CI verification establish source behavior, not a particular deployed Vercel version. Rollback uses a reviewed revert and the existing deployment history, without force-pushing.

11. Cap drawing separately from the fixed simulation, carrying the fractional frame remainder to avoid systematic under-delivery at non-divisible refresh rates. Default to 30 FPS, allow 60 everywhere, require measured display cadence for mobile 90, and offer desktop 120. Touch-device detection does not treat a narrow desktop window as a phone. Saved high desktop rates are capped on phones. Sensitivity changes the actual gesture threshold; a jitter-tolerant double-tap passes the last swipe direction explicitly into dash.
12. Add a dedicated welcome route and move Food play to `/food`; keep direct game links. Role hover/focus artwork uses SVG/CSS. Phone/short guides use four tabs to keep instructions and Play within the viewport. Start artwork animates its arrow while the click target stays steady.
13. Keep music local and gesture-unlocked with a single reusable audio element across routes. Canopy Dawn is an original synthesized piano/violin/viola/cello loop; the reproducible score is in scripts/compose-jungle.py. Python/numpy/soundfile are authoring tools only. Browser runtime dependencies remain unchanged. Audio construction/play failures cannot interrupt navigation or play.
14. Hunter Hard wall candidates use seeded shifts/mirrors, protect actors/items and require connected floor. Current dynamic walls drive movement, spawning, evasion, resize and replay; switching collision terrain happens at the midpoint of the 1.2-second water animation. Canvas status art never changes hitboxes or clocks.
