# Ready-to-use playtest

Build identity: use the exact Preview URL, SHA, deployment ID and date in RELEASE.md. Do not test an unspecified latest build. Record browser/version, physical device or emulation, viewport and input method.

1. Levels: choose each arena/difficulty. Start idle Wild Heart and confirm capture. Move and dash mid-lunge; verify a legitimate baited crash can win. Check hunger/shrinking, bonus and next-arena/retry.
2. Survival: route around Wild Heart roots and stop on the far side; verify current-position pursuit after crashes. Play 10–20 minutes, count resets, and distinguish intentional baits from idle loops.
3. Inputs: hold keys, tap quickly, mix keys and two touch contacts, release/cancel, dash beside the head, pause/resume, change tabs, restart and leave/re-enter routes. Check no stuck or duplicate input.
4. Hunter: collect food, queue corners, try reverse input, enter a departing tail and hit a wall/body. Verify separate results and replay. Record average session length and whether speed is understandable.
5. Local Challenge: repeat the same course and actions after reload; verify fixed setup, capture failure and target success. Compare time then close calls only within that course.
6. Replay/ghost: finish a run with dash and pause, replay it and require final-state verification. Enable a matching mango ghost and check legibility and unchanged collisions. Try unavailable/corrupt storage.
7. UI: test listed desktop, phone and landscape sizes; keyboard focus, native modal close/return, reduced motion, zoom, fullscreen and readable controls. Use real Android/iOS browsers for physical-device claims.
8. Report network/offline, audio failure, missing assets, console errors and frame stutter with their environment. A cached loaded game should keep playing offline; offline first-visit installation is not claimed.

Feedback template: URL/SHA/date; mode/arena/difficulty; device/browser/viewport; input; steps; expected; actual; repeats/attempts; severity; screenshot/video if available. Do not record personal information. Invite independent testers only through a user-authorized channel; no messages have been sent automatically.
