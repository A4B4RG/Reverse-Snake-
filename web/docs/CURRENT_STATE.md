# Current browser product

Updated 14 November 2026. This report supplements the preserved root PROJECT_STATUS.md snapshot; it is a status report, not the completion specification.

The browser product in web/ remains authoritative. Levels and Survival retain five arenas, three difficulties, 20 ms rules, score formulas, dash, close-call boosts, input ownership and backward-compatible local scores. The reported idle Wild Heart Levels win is corrected: both modes plan obstacle/body-aware routes while a lunge already underway remains committed. The original Survival crash/respawn fix remains covered.

Version 1.1.0 adds /hunter (player snake), /challenge (three fixed local survival courses), /replays (completed-run playback), optional matching mango ghosts, a menu that remains accessible on phones, and a board that sizes to the remaining viewport. The main layout has passed twelve viewport checks, including 320 × 568 and 844 × 390. New modes have separate score storage; the existing reverse-snake:v1 key is unchanged. See [mode contracts](NEW_MODES.md).

The current presentation defaults to a light canopy palette; the original dark palette is selectable through Menu → Theme. Page surfaces, dialogs, SVG maps and Canvas follow the selection across all four routes. The separate reverse-snake:theme:v1 preference survives reloads and synchronizes between tabs, with light as the fallback for invalid/blocked storage. Menu opens on desktop mouse hover and toggles on touch or click, provides hover/focus feedback, and supports Escape/outside/close actions. Opening it pauses gameplay or replay, while changing theme preserves the paused characters, time, scores and replay cursor. Both palettes and the open menu fit the tested desktop, phone and short-landscape screens. See [visual direction](VISUAL_DIRECTION.md).

The maintained stack is Next.js 16.4.5, React 19.3.1, TypeScript, Node 24 and Canvas. Phaser, online accounts, cloud scores, custom arena editor, Android package and ML are not implemented. Their conditional deferral is explained in [technical decisions](TECHNICAL_DECISIONS.md).

Current local verification: 44 rules tests, ESLint, production build and TypeScript pass. The browser suite has 43 passes and one explicit headless tab-visibility skip. It covers both palettes and their storage/menu behavior, all-route viewport fit, new modes, replay/ghost, native fullscreen, dialog focus, navigation, offline loaded gameplay and the twelve main-game viewport sizes. The dependency lockfile is unchanged from the previous clean install and zero-findings audit. The startup first-frame reset and dialog focus-return regressions are covered. [Performance evidence](PERFORMANCE.md) contains measurements of the preceding browser release.
